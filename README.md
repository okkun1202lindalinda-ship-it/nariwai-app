# 生業 -Nariwai- 公式サイト

生業のランディングページ、サポート、利用規約、プライバシーポリシーを公開するGitHub Pages用静的サイトです。

- 独自ドメインは使用しない。
- GitHub Pagesの標準URLを使用する。
- 広告、アクセス解析、Cookieを使用しない。
- トップページはApp Storeで公開中の生業を紹介するランディングページとする。
- App Store ConnectのサポートURLは`support/`、プライバシーポリシーURLは`privacy/`を指定する。
- 利用規約は`terms/`で公開する。
- 現在利用できる機能は今後も無料とし、将来追加される機能の一部を有料提供する可能性があることを明記する。
- App Store用スクリーンショットの原本は変更せず、Web向けに軽量化した派生画像だけを`assets/`へ置く。
- レビューと評価は、App Storeで確認できる実在情報だけを掲載する。
- GitHub Pagesは`main`ブランチのルートを公開元とし、`main`への反映後に自動公開する。
- Webページから参照する公開対象は、HTML、`assets/`、`support/`、`privacy/`、`terms/`、`robots.txt`、`sitemap.xml`に限定する。
